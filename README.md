# Propuestas – Jose Khalili, Diseño web

Portafolio de propuestas de sitios web para negocios locales de CDMX, diseñadas por Jose Khalili.

Cada propuesta vive en su propio repositorio y se publica en GitHub Pages:

https://josekb-arch.github.io/propuestas/

Las carpetas de este repositorio redirigen al enlace propio de cada propuesta, para que los links anteriores no se rompan.

Las fotos son ilustrativas (Unsplash) y los datos marcados «por confirmar» deben validarse con cada negocio. No son los sitios oficiales de los negocios.
